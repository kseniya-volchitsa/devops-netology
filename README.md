Репозиторий с домашними заданиями по курсу DevOps.

## Структура

- `02-git-01-vcs/` — Домашнее задание «Системы контроля версий»
- `02-git-02-base/` — Домашнее задание «Основы Git»
- `02-git-03-branching/` — Домашнее задание «Ветвления в Git»
- `branching/` — Скрипты для задания «Ветвления в Git» (`merge.sh`, `rebase.sh`)
